# Glossary Map

## Contexts

- [Shared Platform](./GLOSSARY.md): workspace-wide Call of Duty: World at War 1.7 modding and Classic Mode baseline vocabulary
- [Base Zombies](./docs/contexts/base-zombies/GLOSSARY.md): modular gameplay enhancements layered onto the vanilla four-map Nazi Zombies experience
- [Zombie Gauntlet](./docs/contexts/zombie-gauntlet/GLOSSARY.md): endless multi-map progression mode chaining all four stock maps in escalating round-band passes

## Relationships

- **Base Zombies → Zombie Gauntlet**: Base Zombies enhancements are designed as independent modular features on top of the stock four-map experience, intended to compose cleanly into Zombie Gauntlet later.
- **Shared Platform ↔ Base Zombies / Zombie Gauntlet**: Both contexts share the four Stock Maps, the unmodified Classic Mode baseline, and the unified Mod Package boundary.
