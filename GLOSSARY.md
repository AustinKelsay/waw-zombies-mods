# Shared Platform

Workspace-wide vocabulary shared across all Call of Duty: World at War (vanilla Steam 1.7) Nazi Zombies mods in this repository.

## Language

**Classic Mode**:
Standard, unmodified World at War Nazi Zombies gameplay on any individual Stock Map with all custom game modes and enhancements disabled.
_Avoid_: Vanilla mode, Normal mode, Default mode

**Stock Map**:
One of the four official Call of Duty: World at War Nazi Zombies maps: Nacht der Untoten, Verrückt, Shi No Numa, or Der Riese.
_Avoid_: Base map, Official map, Original map

**Mod Package**:
A self-contained World at War mod build installed under a single `mods/<name>/` folder that players load in-game without modifying core game files.
_Avoid_: Patch, Bundle, Plugin

**Feature Gate**:
A mode or toggle switch that enables or disables a mod capability while leaving Classic Mode completely untouched when off.
_Avoid_: Flag, Toggle switch, Kill switch
